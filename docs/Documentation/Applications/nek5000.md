# Nek5000

## Overview

Nek5000 is an open-source, high-performance computational fluid dynamics (CFD) software package based on the spectral element method. It is designed for simulating incompressible fluid flows, heat transfer, and related transport phenomena.

Nek5000 version 19.0 is installed on Kestrel and supports parallel execution using MPI.

## Loading Nek5000

To load Nek5000 on Kestrel, use the following commands:

```bash
module load nek5000
```


## Running Nek5000 with Slurm

Nek5000 jobs can be submitted to Kestrel using the Slurm workload manager.

The following example uses the `eddy_uv` test case.

Create a Slurm submission script named `nek5000.slurm`:

```bash
#!/bin/bash
#SBATCH --job-name=nek5000_test
#SBATCH --ntasks=2
#SBATCH --time=00:05:00
#SBATCH --output=nek5000_test.%j.out
#SBATCH --error=nek5000_test.%j.err
#SBATCH --account=<your project handle>
#SBATCH --partition=debug

module load nek5000

makenek eddy_uv || exit 1

printf "eddy_uv\n%s/\n" "$PWD" > SESSION.NAME

srun ./nek5000
```

This example requests two MPI tasks for five minutes on the `debug` partition.


## Compiling Nek5000

Unlike many simulation packages, Nek5000 requires compiling the solver for a specific simulation case before execution.

The following command compiles the `eddy_uv` case:

```bash
makenek eddy_uv
```

The command generates the `nek5000` executable in the working directory.

The input files required by the simulation case must be available before compilation and execution.

## Configuring the Session

Nek5000 uses a file named `SESSION.NAME` to identify the simulation case and its working directory.

For the `eddy_uv` example, the file can be generated using:

```bash
printf "eddy_uv\n%s/\n" "$PWD" > SESSION.NAME
```

The file contains two lines:

```text
eddy_uv
/path/to/working/directory/
```

The first line specifies the simulation case name, while the second line specifies the working directory.

## Submitting a Job

Ensure that the required Nek5000 case files are located in the working directory.

Submit the job using:

```bash
sbatch nek5000.slurm
```

The following output files are generated by Slurm:

- `nek5000_test.<jobid>.out`: Slurm standard output
- `nek5000_test.<jobid>.err`: Slurm standard error

Nek5000 may also generate simulation log files and field output files depending on the case configuration.
