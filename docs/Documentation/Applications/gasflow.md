# GASFLOW

## Overview

GASFLOW is a computational fluid dynamics (CFD) software package designed to simulate three-dimensional, transient fluid flow, heat transfer, and gas transport phenomena. It is particularly useful for analyzing gas mixing, dispersion, and related thermal-hydraulic processes.

GASFLOW is installed on Kestrel and supports parallel execution using MPI.

## Loading GASFLOW

To load GASFLOW on Kestrel, use the following command:

```bash
module load gasflow
```

## Running GASFLOW with Slurm

GASFLOW jobs can be submitted to Kestrel using the Slurm workload manager.

Create a Slurm submission script named `gasflow.slurm`:

```bash
#!/bin/bash
#SBATCH --job-name=gasflow_test
#SBATCH --nodes=2
#SBATCH --ntasks=4
#SBATCH --time=00:10:00
#SBATCH --account=<your project handle>
#SBATCH --partition=debug
#SBATCH --output=gasflow_%j.out
#SBATCH --error=gasflow_%j.err

module load gasflow

mpirun -np $SLURM_NTASKS xgfmpi
```

This example requests two compute nodes with a total of four MPI tasks for ten minutes on the `debug` partition.


## Running GASFLOW

GASFLOW uses the executable `xgfmpi` for parallel simulations.

The following command launches GASFLOW using four MPI processes:

```bash
mpirun -np 4 xgfmpi
```

When running within a Slurm job, the number of MPI processes can be specified using the environment variable `$SLURM_NTASKS`:

```bash
mpirun -np $SLURM_NTASKS xgfmpi
```

This ensures that the number of MPI processes matches the total number of tasks requested from Slurm.

Ensure that the required GASFLOW input files are available in the working directory before launching the simulation.

## Submitting a Job

Submit the job using:

```bash
sbatch gasflow.slurm
```

The following output files are generated by Slurm:

- `gasflow_<jobid>.out`: Slurm standard output
- `gasflow_<jobid>.err`: Slurm standard error

Additional simulation output files may be generated by GASFLOW depending on the input configuration.
