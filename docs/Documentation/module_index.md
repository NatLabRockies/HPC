# Module Index

Browse all software modules currently available on NLR HPC systems. This index
is generated automatically from the Lmod module system (`module spider`) and
refreshed periodically, similar in spirit to [packages.spack.io](https://packages.spack.io).

Use the search box to filter by name or description, and the category sidebar
to browse by broad software category (CFD, molecular dynamics, AI/ML, etc.).
Click a module to see its available versions, help text, and the exact
`module load` command to use.
